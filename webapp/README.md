# Archived Noiro browser preview

This code is retained for development reference and is not a customer Noiro
product, deployment target, account client, or playback promise. The canonical
public surfaces are Vortexo Shop, Library, and Studio. Native Noiro keeps media
playback and credentials on the device.

Inherited account and service adapters in this preview fail closed. Do not add a
deployment command or production domain until the rights, security, privacy,
and product reviews explicitly approve a browser client.

Local checks only:

```sh
npm ci
npm run typecheck
npm run build
npm test
```
