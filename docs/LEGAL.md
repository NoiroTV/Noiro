# Noiro legal and product boundary

_Draft updated 2026-08-15. This is implementation documentation, not legal
advice or an approved customer policy._

Noiro is a client-side personal media application intended for sources a user
is authorized to access. Vortexo is the account, commerce, entitlement,
configuration, and software-download control plane.

Vortexo does not receive or store media, playback URLs, Jellyfin addresses or
credentials, provider/debrid keys, arbitrary manifests, downloads, caches, or
Apple credentials. Playback is direct between the user's source and device.

Third-party sources and add-ons remain under their operators' terms. Noiro does
not grant access rights, bypass DRM, or determine whether a source is lawful in
a user's jurisdiction.

The locally held proprietary Stremio `server.js` is not part of the tracked GPL
source. It is a launch blocker: Noiro must obtain written commercial
redistribution and GPL-compatibility permission or replace it with a compatible
open-source implementation before any paid binary is offered.

Noiro's tracked code is GPL-3.0. Each distributed binary requires the exact
corresponding source, dependencies, build instructions, and license notices.
Customers retain the GPL right to redistribute covered code and binaries.

Public registration and sales remain closed until privacy, retention,
processor-disclosure, export, deletion, rights, and name reviews are approved.
